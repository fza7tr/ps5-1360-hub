# PS5 13.60 Hub 0.5.0

## English

- New RAWG game pages show artwork, screenshots, overview, genre, publisher, release information, and clearly separated firmware evidence. Search is delayed and cached; favorites and recent searches are saved locally.
- Source health displays each feed's last attempt, last success, cache age, error, and next retry. Checks run on launch and hourly while the app is in the window or system tray.
- The tray provides Open, Refresh, and Exit. Windows sign-in startup is optional and off by default. Notifications use a baseline and announce only a newly observed official firmware or reviewed jailbreak status change.
- Publisher downloads can resume when the server supports ranges and stable validators. The 512 MB limit is removed. SHA-256 is calculated and compared with a publisher digest when available.
- RAWG keys are protected for the Windows user account with DPAPI, including migration of older saved keys. The key is never sent to the interface after saving.
- English and Arabic layouts, including right to left navigation and reduced motion, are updated across all seven views.

The app does not establish that a public 13.60 jailbreak is available. Commercial game links are listings, and minimum firmware stays Unknown without reliable evidence.

## العربية

- صفحات ألعاب RAWG جديدة تعرض الصور والوصف والنوع والناشر وتاريخ الإصدار، مع فصل الأدلة المتعلقة بإصدار النظام. يُحفظ البحث المؤخر والمفضلة والبحث الحديث محليًا.
- تظهر حالة كل مصدر آخر محاولة وآخر نجاح وعمر البيانات والخطأ وموعد المحاولة التالية. يستمر الفحص كل ساعة أثناء تشغيل التطبيق في النافذة أو منطقة الإشعارات.
- توفر منطقة الإشعارات خيارات الفتح والتحديث والخروج. بدء التشغيل مع Windows اختياري ومعطل افتراضيًا. لا تُرسل التنبيهات قبل تكوين خط أساس أولي.
- يمكن استكمال تنزيلات الناشرين عندما يدعم الخادم الطلبات الجزئية ومعلومات التحقق الثابتة. أزيل حد 512 ميغابايت ويُحسب SHA-256 لكل ملف.
- يُحمى مفتاح RAWG بحساب Windows باستخدام DPAPI، مع نقل المفتاح المحفوظ من الإصدارات السابقة.
- تحسنت الواجهات العربية والإنجليزية والاتجاه من اليمين إلى اليسار وخيار تقليل الحركة في الأقسام السبعة.

لا يثبت التطبيق توفر كسر حماية عام لإصدار 13.60. روابط الألعاب التجارية صفحات معلومات، ويظهر الحد الأدنى للنظام «غير معروف» عند غياب دليل موثوق.
